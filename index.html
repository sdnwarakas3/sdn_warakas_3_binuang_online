💾 Penyimpanan Foto

Laptop adalah penyimpanan foto utama. HP mengirim foto ke server sementara, lalu laptop mengambil dan menyimpannya.

Mode perangkat saat ini:

🔧 Diagnostik Sinkronisasi Foto

Gunakan ini untuk memastikan HP/laptop benar-benar terhubung ke server foto. Tidak menghapus data.

⚙️ Pengaturan Identitas

Identitas dapat diubah dari menu ini dan tersinkron ke semua perangkat/aplikasi. Tanggal, bulan, dan tahun cetak mengikuti tanggal nasional Indonesia (WIB) secara otomatis dan tidak dapat diubah.

🪪 Setelan Kartu Anggota

Model kartu mengikuti desain referensi: ukuran KTP, logo kop dapat di-upload, ilustrasi otomatis mengikuti jenis kelamin, dan semua perubahan berlaku otomatis untuk seluruh anggota.
